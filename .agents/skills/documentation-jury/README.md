# Skill : documentation-jury

## Rôle

Produire et maintenir la documentation nécessaire pour la soutenance DWWM. Transformer le travail technique en preuves exploitables par le jury.

## Quand l'utiliser

- À chaque livraison d'une fonctionnalité (collecter les preuves)
- Pour préparer le dossier professionnel
- Pour réviser avant la soutenance
- Quand on se demande "est-ce que le jury va comprendre ça ?"

## Niveau attendu

Documents clairs, concis, en français correct. Un jury peut lire un document technique sans être développeur — adapter le niveau de détail en conséquence.

## Bonnes pratiques

- Un document = un seul sujet (pas de fourre-tout)
- Mettre des exemples de code commentés dans le dossier professionnel
- Inclure des schémas visuels (BDD, flux, architecture)
- Dater les documents importants
- Collecter les preuves en continu, pas à la fin

## Ce que le jury valorise

- La compréhension réelle (pas le copier-coller)
- La cohérence entre le code et la documentation
- La prise en compte de la sécurité
- La capacité à expliquer ses choix
- Des tests documentés (même manuels)

## Erreurs à éviter

- Rédiger le dossier professionnel à la dernière minute
- Inclure du code sans l'avoir compris
- Omettre les cas d'erreur dans les scénarios de test
- Ignorer la partie sécurité (très regardée par les jurys)
- Dossier trop long et illisible > dossier court et précis

## Checklist du dossier professionnel

- [ ] Présentation du projet en 1 page (contexte, besoin, solution)
- [ ] Architecture technique illustrée d'un schéma
- [ ] Schéma de base de données à jour
- [ ] Au moins 2 extraits de code commentés par CCP
- [ ] Documentation de l'authentification (flux complet)
- [ ] Scénarios de test documentés
- [ ] Instructions de déploiement
- [ ] Bilan personnel (difficultés + apprentissages)

## Checklist avant la soutenance

- [ ] Démo fonctionnelle en local (tester la veille)
- [ ] Réponses préparées pour les questions jury (voir `docs/jury/QUESTIONS_JURY.md`)
- [ ] Schémas imprimables ou en PDF
- [ ] Backup du projet (clé USB ou cloud)
