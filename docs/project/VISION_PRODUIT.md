# Vision Produit

## En une phrase

Permettre à n'importe quelle équipe de conduire une rétrospective agile efficace, sans friction technique, depuis un navigateur web.

## Problème résolu

Les rétrospectives agiles sont souvent mal outillées :
- Les post-its physiques ne fonctionnent pas en remote
- Les outils génériques (Miro, Jamboard) sont trop ouverts et perdent les équipes
- Les solutions dédiées existantes sont souvent payantes ou trop complexes

## Solution proposée

Une application web simple et focalisée :
- Le facilitateur crée une session en 30 secondes
- Les participants rejoignent sans créer de compte (à évaluer)
- Tout le monde peut écrire, voter, discuter dans un cadre structuré

## Valeur ajoutée

| Pour le facilitateur | Pour le participant |
|---|---|
| Contrôle total sur la session | Interface claire et sans distraction |
| Vue d'ensemble des thèmes émergents | Anonymat possible si souhaité |
| Historique des sessions passées | Accès rapide sans installation |

## Ce que ce n'est PAS

- Un outil de gestion de projet complet
- Un outil de communication (pas de chat)
- Un outil de reporting avancé

## Indicateurs de succès

- Une session peut être créée et conduite en moins de 5 minutes de setup
- Les participants peuvent rejoindre et ajouter une carte en moins de 1 minute
- Le facilitateur peut voir les résultats triés par votes en un clic
