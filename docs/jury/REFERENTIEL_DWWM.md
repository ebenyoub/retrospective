# Référentiel DWWM — Couverture par le projet

## CCP1 — Développer la partie front-end d'une application web ou web mobile sécurisée

### Compétences

| # | Compétence | Couverture dans le projet | Statut |
|---|---|---|---|
| C01 | Installer et configurer son environnement de travail en fonction du projet web ou web mobile | Vite + React + TypeScript configurés | ⬜ À documenter |
| C02 | Développer des interfaces utilisateur web statiques et adaptables | Pages et composants React | ⬜ À faire |
| C03 | Développer des interfaces utilisateur avec des composants d'interface dynamiques | Formulaires, cartes rétrospective interactives | ⬜ À faire |
| C04 | Développer la partie front-end d'une interface utilisateur web dynamique avec des composants connectés à un back-end | Context + Fetch vers l'API Express | ⬜ À faire |
| C05 | Réaliser les tests unitaires d'un composant d'interface utilisateur web avec un framework de tests adapté | Tests des composants clés | ⬜ À faire |
