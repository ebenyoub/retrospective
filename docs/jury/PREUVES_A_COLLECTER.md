# Preuves à Collecter pour le Jury

> Compléter au fur et à mesure du développement. Chaque preuve doit être datée et localisable.

## Preuves techniques

### Code source
- [ ] Lien vers le dépôt Git (ou archive)
- [ ] Historique de commits montrant la progression
- [ ] Extrait du middleware d'authentification JWT commenté
- [ ] Extrait d'un contrôleur Express complet commenté
- [ ] Extrait d'un composant React avec gestion d'état commenté
- [ ] Script SQL de création de la base de données

### Captures d'écran application
- [ ] Page de connexion
- [ ] Page d'inscription
- [ ] Tableau de rétrospective avec des cartes
- [ ] Interface de vote
- [ ] Vue facilitateur vs vue participant
- [ ] Message d'erreur (validation formulaire)
- [ ] Démo de l'authentification fonctionnelle

### Tests
- [ ] Captures des tests passants
- [ ] Scénarios de test documentés
- [ ] Rapport de test si outil automatisé utilisé

## Preuves de conception

### Modélisation
- [ ] Schéma de la base de données (MCD ou MLD)
- [ ] Diagramme des routes API
- [ ] Flux d'authentification (schéma)
- [ ] Maquettes des interfaces (wireframes ou screenshots Figma)

### Documentation
- [ ] `docs/technical/ARCHITECTURE.md` complété
- [ ] `docs/technical/API.md` complété avec toutes les routes
- [ ] `docs/technical/DATABASE.md` avec le schéma final

## Preuves de démarche

### Git
- [ ] Messages de commit lisibles et réguliers
- [ ] Branches utilisées (si applicable)
- [ ] Au moins 20 commits significatifs

### Suivi de projet
- [ ] `docs/PROJECT_STATE.md` tenu à jour
- [ ] `docs/CHANGELOG.md` avec les livraisons
- [ ] Backlog avec les fonctionnalités priorisées
